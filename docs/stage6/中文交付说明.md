# 阶段6交付说明

日期：2026-11-15。课后反馈与成长报告的后端已按冻结接口v0.3.7完成，等待本阶段验收。

老师可以把每个孩子的课后情况写成标签、曲目、四段点评和图片，仍走原有提交与确认流程。默认员工确认后才扣课、计酬和向家长公开；主管也可以开启自动确认。无法销课的孩子不会被错误公开，老师修改后的新点评在确认前也不会覆盖家长正在看的版本。

机构可以创建报告批次、为学员分配老师、填写人工评分和模拟考、对照CRM统计、完成待发、发布或撤回。报告修改工作稿时，家长继续看已发布版本。历史维度、班型选项、集训识别和风格保存快照，不随新设置改变。家长时间线合并了已发送方案、已确认反馈和已发布报告，只能看已绑定孩子的内容及获准图片。

AI提供反馈整理、单人报告文字和批量起草；最多100人一批，按成功人数计次，额度不足返回实际处理与跳过名单。AI不写报告、不打分、不改业务进度，仍由人采用后保存。模型、数据库和图片均用本地模拟验证，没有接入真实云资源、真实AI或线上数据，没有部署。
