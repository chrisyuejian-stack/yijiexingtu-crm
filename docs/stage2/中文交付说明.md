# 阶段 2 · 身份与机构交付说明

本阶段完成艺界星途的登录、账号、家长绑定与机构管理后端。实现依据为冻结接口 v0.3.3，第 0–8 节；您已经确认的选择均已采用，本阶段没有新增需要您决定的事项。

## 已完成

- 员工可以从根地址登录。同一手机号在多家机构且密码通过时，先选机构；老师、学员和家长使用机构专属入口。两种登录返回对应的接口前缀。
- 增加顾问和家长角色，支持员工角色组合；财务计入管理账号数量。新增权限和模块开关已进入原权限体系。
- 支持为孩子开家长账号、绑定多位家长、修改称呼、解绑、重置密码和停用。最后一个孩子解绑后自动停用；人工停用的家长不会因重绑自动恢复。
- 机构停用或到期后，有效登录会被拦截，但不被删除；恢复或延期后，仍有效的登录可以继续使用。超级管理员也可单独强制全机构退出登录。
- 平台可创建和修改机构、设置有效期和管理账号上限、品牌、模块、学科选择及 AI 上限覆盖。新机构继续使用原有主管开通流程。
- 学员新增报告班型、来源线索、AI 称呼和展示照片授权字段。新身份数据已纳入备份结构。
- 统计报表与成长报告的权限及开关分别保存，原财务报表和导出继续可用。

源码与构建产物的通过数、原测试修订详情及实际日志见[测试结果](测试结果.md)和[变更清单](变更清单.md)。[前端对接说明](前端对接说明.md)附本地真实请求和响应，可直接交给 Claude 制作模拟数据。
