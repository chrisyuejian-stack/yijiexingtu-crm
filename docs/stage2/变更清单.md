# 阶段 2 变更清单

比较基准是最早已归档的项目底座源码 ZIP。它早于接口 v0.3 与更新设计稿的材料整理，因此完整差异 JSON 也包含阶段 2 开工前的材料更新；这些归档差异不算新增业务功能。原 CRM 文件哈希基准位于 `docs/reference/crm-baseline-sha256.json`。本阶段未删除或跳过原测试，未改动前端文件。

## 新增文件与迁移

| 文件 | 用途 |
| --- | --- |
| `migrations/0019_identity_and_institutions.sql` | 新身份字段、索引、选择令牌、家长绑定、学科选择与 AI 覆盖；替换机构会话撤销触发器；索引同步及席位约束 |
| `src/server/identity.js` | 根登录、选择机构、会话类型、家长与平台机构管理服务及新错误格式 |
| `scripts/rebuild-platform-phone-index.mjs` | 仅超管可调用的索引重建维护适配器，本地测试验证，未操作远程资源 |
| `tests/identity-stage2.test.mjs` | 新增 28 项自动测试与真实 HTTP 示例采集 |
| `docs/reference/接口约定_v0.3.1_原件.md`、`接口约定_v0.3.2_原件.md`、`接口约定_v0.3.3_原件.md`、`设计稿_v3_原件.html` | 接口演进和设计原件；最新 v0.3.3 为实现依据，v3 仅用于理解数据 |
| `docs/阶段2_开工阻塞说明.md`、`docs/阶段2_回归断言阻塞说明.md` | 保留已解决问题与授权过程的历史记录 |
| `docs/stage2/` | 中文交付、变更、测试、对接说明、真实 JSON、最终日志及文件哈希清单 |

本阶段仅新增迁移 **0019**。0001–0018 的 18 个文件与 CRM 基准逐字节一致。0019 增加 `platform_phone_index`、`login_choices`、`guardian_links`、`tenant_subjects`、`tenant_ai_overrides`，扩展 users / sessions / students；不创建后续阶段的内容、方案或成长报告表。
