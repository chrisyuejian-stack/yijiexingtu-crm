# 艺界星途 v0.5 · 学员方案重构设计稿（2026-11-17）

**蓝本**：枫琴工具站 v6.0 的学生方案生成器（`plan/index.html` + `studio2-plan.js`），已在本地跑过，13 页样张全部看过。

**目标**：方案的结构、灵活度和 AI 能力都达到枫琴的水平，同时适用于各类机构：艺考、考级、留学、少儿启蒙、美术、舞蹈。

**数据原则**：系统里的课程、价目、老师、学员只是辅助，不是限制。

- 每个版块都可以自由填写。
- 从系统里选，只是“一键带入”的捷径。
- 严格的只有两处：金额由程序算（自由填的单价也由程序乘加），以及广告法检查。

## 1. 方案结构（doc v2）

| # | 版块 | 内容 | 系统数据怎么辅助 |
|---|---|---|---|
| 1 | 基本信息 | 学员姓名、年级、方案日期、方案标题、专业方向；英文专业方向（可选，打开“英文字段”开关后才显示）；是否要封面 | 学员、线索、意向信息带入姓名和年级 |
| 2 | 学员测评 | 自由长文，支持 `**重点**` 加粗和 `- ` 列表；可选附几项打分或标签 | 无 |
| 3 | 学习 / 申请策略 | 自由长文 | 无 |
| 4 | 学习路径 | 若干阶段：名称、起止月份（时长自动算）、目标要点；阶段内可加带日期的小节点（如“暑期音乐节”） | 学科包的阶段类型可以一键带入 |
| 5 | 关键节点时间线 | 日期、事件、类型（考级、比赛、艺考、申请截止、演出、其他）、备注。**考级规划和比赛规划都放在这里** | 学科包的节点日历可以一键带入 |
| 6 | 课程计划 | 按阶段分组，组内再分组（如“基础 / 核心”，组名可改）。每行：课程名、英文名（可选）、频率文字（每周 1 次 · 每次 1 课时）、每课时分钟数、课时数、单价、备注。显示阶段小计和总课时。整个阶段可以写成“待定”加一段说明 | 从课程库选，会带入名称、单价和默认频率；也可以直接新增**自由课程**（手填单价，带“非价目表”标记，导出前提醒确认） |
| 7 | 师资 | 按角色分组（如“声乐主专业导师”）。每位老师：姓名、头衔、介绍（长文）、照片（可选）、“拟”标记 | 从系统老师里选会带入姓名；**也可以直接填写系统里没有的老师** |
| 8 | 费用与缴费 | 各阶段费用（由课程计划自动汇总，可加阶段附加费）；其他费用（申请服务费等）；优惠；总计。分期表：日期、内容、金额，可以按阶段一键生成 | 金额由程序算 |
| 9 | 目标院校 / 目标 | 多组，每组有标题（如“英国院校”“目标级别”）。每项：名称、英文名（可选）、档次（冲刺 / 主申 / 保底，或自定义）、备注 | 以后接院校数据库时，从库里一键带入 |
| 10 | 附加照片页 | 多页，每页有标题和 1–8 张图（校区环境、成果、录取通知等），可选排版 | 从图库选 |
| 11 | 机构介绍 | 沿用现有版块 | 机构档案 |

**每个版块都可以显示或隐藏、调整顺序。** 第 2–9 版块的标题可以改名，比如把“目标院校”改成“考级目标”。

**整体平移日期**：输入 N 个月，往前或往后。学习路径、时间线、分期日期、方案日期一起平移。

## 2. 方案模版和“学习过往方案”

### 2.1 机构方案库

- 任何方案都能“存为本机构模版”：保存一份去掉学员身份信息的副本，并填写模版名和适用说明（专业方向、年级段、预算段）。
- 新建方案时可以“从模版开始”。选中后会提示要不要平移日期。
- 平台给每个学科提供 1–2 份示例模版。示例模版存在学科包里，由平台发布，机构不能修改。

### 2.2 AI 学习过往方案（不训练模型，用检索）

- **参考来源**：本机构“已签约”的方案，加上本机构的模版。顾问也可以手动把某份方案标为“优秀方案，可供参考”。
- **找相似方案**：生成建议时，后端按学科、专业方向、年级、预算、目标类型，从参考来源里挑出最相似的 3–5 份。
- **只发结构，不发个人信息**：阶段划分、各阶段时长、课程组合和课时、费用区间、时间线的节点类型、策略和测评的写法片段，都以摘要形式作为参考发给 DeepSeek。
  - 必须去掉学员姓名、家长信息、电话、学校。
  - 测评正文只发摘要，不发全文。
- **界面上不展示参考过程**：不显示“参考了几份方案”或任何检索细节。用户只看到更贴合本机构习惯的建议。
- **成本**：每次请求的提示会变长，DeepSeek 费用会增加，估计每次多 2,000–6,000 token。不需要新的 Cloudflare 或 DeepSeek 设置。

## 3. AI 助手（参照枫琴 studio2-plan）

- **默认“自动判断”**：顾问只说一句话，比如“考级推迟一个月，每周加一节视唱，预算 2 万以内”。AI 判断要改哪些版块，一次返回多版块修改，按版块分组展示。每组都可以单独“采用 / 不要”，并支持撤销。左边的选择框保留，用于手动指定版块。
- **整理咨询记录**：粘贴聊天记录、面谈纪要或测评，返回逐字段建议。每条建议显示原值（删除线）、新值、对应的原话；能核对出原话的默认勾选，属于推断的标黄、默认不勾（照搬枫琴的卡片样式）。学员测评、策略、目标院校、时间线都可以从这里填。
- **长输入框：顾问直接描述情况**
  - AI 助手顶部常驻一个多行大输入框（不少于 6 行，可拉高，单次 ≤ 8000 字）。顾问用口语直接打字，例如“孩子初二，钢琴 6 级，手型有点塌，家长想走艺考，预算一年 3 万左右……”。
  - AI 把它整理、润色成能直接放进方案的正式文字，自动分到对应版块：学员测评、学习策略、目标、时间线节点、课程偏好等。每个版块一张建议卡，可以“采用 / 修改后采用 / 不要”。
  - 输入框里的原文随方案保存（仅员工可见，不导出、不分享），下次打开还在，可以补充后再整理。
  - 这个输入框就是“自动判断”的入口：说明情况和提出修改要求用同一个框，AI 自己判断是“填写”还是“修改”。
  - **同步生成阶段和课程**：整理完文字后，AI 接着根据这段情况（年级、水平、目标、时间点、预算、每周可上课次数等），生成“学习路径”的阶段和“课程计划”的各阶段课程，课时和频率都要配好。
    - 优先使用课程库和价目表里的课程，需要时提出自由课程，并带“非价目表”标记。
    - 金额由程序算，并和预算对比。
    - 阶段卡和课程卡跟文字卡一样，可以逐张采用。
    - 已经有阶段和课程时，显示为“修改建议”（原值删除线 → 新值），不直接覆盖。
- **阶段与课程**：根据测评、目标、预算和相似过往方案，生成阶段划分和课程组合。优先用课程库里的课程，需要时提出自由课程（标记出来）。
- **报价**：按价目表和自由单价汇总，算出分阶段费用和分期，并和预算对比。
- **润色**：只改文字版块。
- **选中范围**：在编辑区选中某个版块时，AI 只处理这个版块。
- **严格项**：金额只能由程序计算，AI 不得输出金额；广告法检查保留。

## 4. 版式

- A4 页面。封面沿用现有三套（舞台 / 画册 / 手札），内页参照枫琴：
  - 小节标题用“斜体英文眉题 + 中文大标题 + 渐变短线”；
  - 课程表是“中文名 / 斜体英文名 + 频率 + 课时”三列；
  - 师资是“角色列 + 姓名、头衔、介绍”双栏；
  - 费用页底部是深色总价条；
  - 照片页是 2×3 或 3×3 网格。
- 风格包继续控制颜色、字体和组件变体。新增版块的组件变体（时间线、目标院校、照片页）在风格包格式里补充说明。
- 导出 PDF 时，文件名是“学员方案-姓名”，不出现空白页，页眉页脚显示机构名和页码。

## 5. 数据和迁移（GPT）

- 不改 `plans` 表结构。新结构写在 `doc_json` 里，加 `doc_version: 2`。
- 旧方案（v1）在读取时自动转换成 v2，下次保存时写回 v2。转换规则：
  - `assessment` 的三个列表合并成测评长文；
  - `path` 转为学习路径；
  - `courses` 按阶段分组成课程计划；
  - `teachers` 转为师资（保留系统老师 id）；
  - `fees` 原样保留。

  转换必须可逆检查。旧的分享链接显示的是已发送的修订版本，修订快照不改，按 v1 渲染。
- 模版和“优秀方案”标记：新增表 `plan_templates`；或给 `plans` 加 `ADD COLUMN reference_flag INTEGER DEFAULT 0`。由 GPT 选定，只能新增。
- 金额计算沿用 `plan-math`，扩展到自由课程（单价 × 课时）和附加费。

## 9. 公众号编辑器增强（同在 v0.5，参照枫琴公众号编辑器）

**用户要求**：撤回和重做放在编辑窗口上方的明显位置；要有加粗、斜体、高亮等基础文字格式。

**前端（Claude）**：

编辑区上方加固定工具条，分组照搬枫琴：

| 分组 | 内容 |
| --- | --- |
| 插入 | 段落、小标题、图片、表格、列表、引用、分隔线等 |
| 修改 | ↶ 撤销、↷ 重做 |
| 文字 | **B** 加粗、斜体、荧光笔高亮、品牌色强调、清除格式 |

- **撤销 / 重做**：
  - 记录整篇快照，连续打字停顿约 1 秒后算一步；
  - 覆盖所有编辑：打字、插入、删除、移动、AI 采用；
  - 最多保留 50 步；
  - 快捷键 ⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 或 Ctrl+Y 重做；
  - 没有可撤销或可重做的步骤时，按钮置灰。
  - 原来 AI 面板底部的“撤销”并入这里。
- **块操作条**：选中一块时，旁边浮出 ↑ 上移、↓ 下移、⧉ 复制、✕ 删除。删除后提示可以撤销。
- **文字格式范围**：只作用于同一段里选中的文字；没有选中文字时提示“先选中要设置的文字”。
- **复制到公众号、导出长图**：格式按内联样式输出（加粗、斜体、高亮底色、品牌色）。

**后端（GPT）**：

- **存储格式**：块文本里支持轻量内联标记：
  - `**加粗**`
  - `*斜体*`
  - `==高亮==`
  - `[[品牌色强调]]`

  不能嵌套到第二层。由 GPT 确认最终语法，并写进接口约定。
- **长度和校验**：长度限制按去掉标记后的文字计算；标记不成对时，保存时规整为纯文字，不报错。
- **AI 动作**（rewrite / section / versions）：
  - 输入可以带标记，输出要保留原有标记；
  - 允许 AI 少量使用加粗和高亮，标出重点。
- **flags、fact-check、广告法检查、禁用词**：先去掉标记再匹配，quote 返回纯文字。
- **旧内容**：没有标记，原样兼容，不需要迁移。
