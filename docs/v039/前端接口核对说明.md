## article新增字段

PUT `{api_base}/content/{id}` 带当前version和可选article，GET同一路径返回article，旧内容为null。POST新建也接受相同校验。api_base继续使用登录返回值，不硬编码机构slug。

- article整体替换；不带article保留原值，article:null清除。只提供部分键时仅保留该次提供的键，不自动补造产品默认值。
- column、author为≤20字纯文本；空字符串保留，显示时由前端使用场景/机构名。publish_date为真实YYYY-MM-DD，空字符串或null规范为null，显示回退更新日期。
- header_image_id为本机构有效图库ID或null；不存在、外机构、已删统一422 invalid_image。隐藏图片按既有图库规则：不能新选，已经使用的隐藏头图可保留。头图纳入修订图片引用，校验后并发删除会整次回滚。
- footer.qr/address为布尔开关，字段可省略；二维码引用settings/brand.qr_image_id，地址和上课时间引用settings/profile.address/class_hours，不把真实资料写入article。未知自定义属性不落库。
- content_items.article_json保存人工信息；不可变content_revisions.doc_json保存当时article快照，两处都进入现有加密备份。AI读取的正文JSON不包含article，AI输出白名单也不会返回它；人工采用正文建议而保存时未带article，原值保持。

**当前前端尚未接入：** yxcSave的body没有article，yxcPreview仍取第一张图片/机构名/更新时间，yxcCopy仅复制正文块。按用户“不改界面”的要求均未改；Claude需要补article读写、头图和署名日期回退、footer两种资料的复制/导出。旧文章为null时继续原第一张图片逻辑。不能把“后端已支持”写成“界面已能编辑或复制这些内容”。

## 两个只读字段

GET `{api_base}/reports/{id}` 追加feedback_count整数。按报告首尾日期（含边界）、该学员、当前已确认且可用的反馈统计；旧纯文字流程也兼容。一个课次中公共/个人点评或多个已确认修订不重复算，待审/退回不单独增加；已确认旧版本仍可用时继续算一条。只读，伪造写入无效，不改变原报告状态、评分、统计快照或发布规则。

GET `{api_base}/feedback/today` 的每个items项追加student_names字符串数组，最多6个，按参与记录创建时间/id稳定排序；排除已删除参与者/学员，零学员返回[]。范围仍为本人主讲/助教课程，不增加其他人权限。前端已经读取这两个字段，直接使用返回值即可。

两份Worker最终都因后端增量而变化，不能把纯前端融合“Worker相同”的结论用于最终包。详细哈希、真实请求JSON和测试命令随交付提供。未连接真实云资源或模型，未做新界面视觉验收。

GET reports的feedback_count是只读扩展；若前端保存后用PUT响应整体替换本地报告对象，随后需保留该展示值或重新GET。它不由客户端写入，也不进入评分/报告正文。
