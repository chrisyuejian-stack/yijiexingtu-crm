## 修改的既有代码

| 文件 | 修改原因 |
| --- | --- |
| `src/server/repo.js` | 所有新 SQL 与机构限定；原子设置写入、引用与版本守卫、模板导入、审批回滚、Excel 预览/确认；新表进入全量快照；ops 保存学科时同事务导入并保留既有导入标记 |
| `src/server/worker.js` | 两种机构会话路径接入新服务与新错误格式，保留融合版批量读取与机构品牌逻辑 |
| `src/server/scheduling.js` | 姓氏称呼默认值、报告班型机构归属校验、关联字段显式清空 |
| `src/server/identity.js` | 新家长绑定 link DTO 去掉 tenant_id，ops AI 覆盖 DTO 只返回约定限额字段 |
| `src/server/backup-model.js` | 新表/新字段加入全量加密备份模型；原业务恢复范围不变 |
| `src/server/purge-schema.js` | 新表按依赖顺序纳入机构清理；图库 R2 路径放在原机构清理命名空间内 |
| `tests/support.mjs` | 所有正常测试加载0020，新增仅供升级用例的 migrateSettings=false 前置场景；原断言不改 |

机构上下文仍由认证会话确定，新业务 SQL 全部在 repo 层限定 tenant_id。原 CRM `/api/me` 的 tenant_id 是底座已有字段，按用户“既有字段不变”的要求保留；新设置、家长 link、ops 覆盖等新 DTO 不再输出该键。
