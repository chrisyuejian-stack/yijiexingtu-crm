## 公共调用约定

平台接口固定在平台主机 `/api/ops/...`，要求Cloudflare Access及已登录的owner超管。Access头由Cloudflare注入，前端不要自填或暴露令牌。浏览器同源fetch携带会话Cookie；JSON写请求用Content-Type: application/json并保持同源Origin。多分工的机构员工/平台consultant没有平台管理权限。新DTO不输出tenant_id；作用域对象用id，平台管理请求里的tenant_ids和用量筛选tenant_id按冻结协议保留。

机构接口必须以登录返回的api_base拼接：根会话/api，路径会话/{slug}/api。下面机构路径示例都来自路径会话；不要在前端硬编码演示slug。未命中、跨机构、模块未开为404，停用/到期且有效会话为403 tenant_expired。遵循通用message/error/details，不自行把403当登出删除会话。

## 学科包

| 方法和路径 | 发送 / 读取 |
| --- | --- |
| GET /api/ops/subject-packs | items含key、name、current_published_version；versions含完整content、pack_version、整数version、status、published_at |
| POST /api/ops/subject-packs | {key,name?,pack_version,content}，创建草稿201，当前整数version=1 |
| PUT /api/ops/subject-packs | {key,name?,pack_version,version,content}，完整保存草稿；成功version递增 |
| POST /api/ops/subject-packs/{key}/versions/{pack_version}/publish | {version}；发布后不可编辑或覆盖，只能另建新pack_version |
| POST {api_base}/settings/subjects | {key}，显式导入当前发布版；再次同版幂等；已有机构不会因平台发布自动更新 |

pack_version是内容版本字符串，如0.2；version是防并发整数，不是同一字段。PUT旧version返回409 version_conflict，details.latest是完整最新草稿；提示用户核对后重新保存，不能自动覆盖。发布内容再PUT返回409 invalid_state。

content完整结构含courses、stages、rules、calendar、course_rules、classes、content_types、constraints、tone。从真实GET复制一个0.1草稿再编辑最稳妥；随部署资料提供0.2请求示例。仅四种已冻结学科。课程、阶段、班型、日历/维度都保留稳定key，改名称不改key；新条目使用新key，不把机构对象ID当key。pricing只可为null，不传金额、快照或任何机构ID。

course_rules通过stage_key及课程key引用，required/recommended为课程key数组，exclusive为课程key数组的数组，units为{min,max}。导入时后端映射成本机构ID。同名手建对象不会冒充模板条目。映射/引用不全整次422，不会留下半套课程；提示用户修正模板引用。新版本只追加缺失key，不覆盖机构原名称、价格、维度、日历和规则；删除平台条目也不自动停用机构条目。历史改名条目不能唯一识别时GET/settings/subjects会有warnings，保留原数据，请展示警告而不是按名字自动关联。

## 风格包管理

| 方法和路径 | 请求 / 响应重点 |
| --- | --- |
| POST /api/ops/style-packs/upload | FormData，唯一字段file，值为zip；201返回pack_id、pack_version、整数version、status=draft、manifest、checks |
| GET /api/ops/style-packs | items各包含versions、active、current_version，defaults按四种doc_type分别列出 |
| GET /api/ops/style-packs/{id} | 详情、versions、scopes（机构id和pack_version）、used_count |
| POST /api/ops/style-packs/{id}/versions/{v}/preview | {}；previews按manifest.doc_types返回doc_type/render_data/manifest/asset_base |
| POST /api/ops/style-packs/{id}/versions/{v}/publish | {scope,tenant_ids,version}，scope为admin_only、tenants、all；tenants必须有有效机构ID，另两类传[]或省略 |
| POST /api/ops/style-packs/{id}/disable | {}，停止新选用，历史文档不换包或图片 |
| PUT /api/ops/style-packs/default | {doc_type,pack_id}；plan/report/feedback_card/article各自保存 |

上传不能手工设Content-Type，否则缺少multipart boundary。前端发送真实ZIP，示例JSON中的{multipart:true,file:"style.zip"}仅描述文件请求，不是实际JSON请求体。包根只有manifest.json与assets中的PNG/JPEG/WebP，压缩和解压总量各≤10MiB，单图≤2MiB；SVG、脚本、HTML、字体、隐藏文件均不允许。重复id+pack_version返回409 duplicate，不原地覆盖已上传版本。校验失败返回422 style_pack_invalid，details附检查错误；检查errors阻断不生成可发布版本，warnings如图片过窄仍可草稿/发布，应在界面明确提示。

manifest完整格式见真实上传示例[07.json](frontend-examples/07.json)及部署资料示例ZIP。六个组件键和字体严格白名单，不能用自定义CSS/URL。字体只允许noto-sans-sc、noto-serif-sc、cormorant-italic；组件变体按§6选择。已发布风格/素材不可变，新设计另用新版本。

preview的render_data是完整平台虚构示例，可直接喂现有对应渲染器，不调AI、不读真实机构/学生数据、不创建业务文档。示例均有example:true。默认包对某机构不可用时服务端从该机构仍可用包回退；全部不可用返回明确422错误，前端提示联系平台，不自行借用越权包。

### 图片和asset_base

manifest图片保持assets/pic.png这样的包内相对路径。把开头的`assets/`去掉，用`asset_base + 剩余路径`读取；例如asset_base为`/api/ops/style-packs/demo_platform_style/versions/1.0.0/assets/`，相对文件为`assets/pic.png`，实际URL结尾应为`/assets/pic.png`，不能出现重复assets/assets。不要修改manifest内路径或换成公开R2地址。

| 场景 | 数据/manifest来源 | 图片URL来源 |
| --- | --- | --- |
| 平台草稿/预览 | 平台详情或preview | /api/ops/style-packs/{pack}/versions/{v}/assets/{asset_path} |
| 机构当前/自己的历史文档 | GET {api_base}/styles/{pack}/versions/{v} | 返回asset_base + 路径；该前缀为{api_base}/styles/.../assets/ |
| 家长已发送方案 | GET {api_base}/parent/plans/{id} | 返回asset_base，前缀为{api_base}/parent/plans/{id}/style-assets/ |
| 家长已发布报告 | GET {api_base}/parent/reports/{id} | 返回asset_base，前缀为{api_base}/parent/reports/{id}/style-assets/ |
| 公开分享 | GET /api/share/{token} | 返回asset_base，前缀为/api/share/{token}/style-assets/ |

图片接口返回真实二进制Content-Type:image/...、private/no-store、nosniff；JSON捕获为便于前端模拟用base64展示。家长绑定与可见修订、分享固定修订决定权限；不要持久缓存为公开图片，作废分享/撤回报告后重新取图按规则失败，历史锁定包在停用或发布新版本后仍可读。未知资源、跨机构、路径穿越统一404。老师只能读报告/反馈卡片风格，财务保留旧统计报表且不能读纯成长报告风格。

### 前端必须继续完成的检查

服务端上传检查固定ink/paper、muted/paper及primary上的light或dark文字是否≥4.5，并返回checks.usable_text_modes。**实际机构主色替换和照片背景不在上传时可知**。预览/导出必须检查实际颜色和实际照片文字区域；不足时调整文字或使用安全面板。不要把“上传通过”显示为“所有实际页面已通过对比度/视觉验收”。本次未改页面，需前端接入后另做真实预览与导出验证。

## AI额度、用量和平台词库

| 接口 | 请求 / 响应 |
| --- | --- |
| GET /api/ops/ai/settings | 既有平台设置，含version、两档模型与默认上限 |
| PUT /api/ops/ai/settings | 带最新整数version及fast_daily_limit、deep_daily_limit、fast_model、deep_model；旧version409附latest |
| PUT /api/ops/tenants/{id}/ai-override | 两个*_daily_limit均须传，非负整数或null；0禁用该档，null恢复平台默认；返回id与两项值 |
| GET /api/ops/ai/usage?from=YYYY-MM-DD&to=YYYY-MM-DD&tenant_id=...&group=day | 含首尾北京时间日期；group还可tenant/tool；tenant_id可省略；items含key/tier/calls/successful/failed/prompt_tokens/completion_tokens/duration_ms |
| GET /api/ops/compliance/terms | {items:[{id,term,active,version}]} |
| PUT /api/ops/compliance/terms | {terms:["包过","保录"]}，完整保存词条集合，返回当前items并留平台审计 |

用量三种group均有非空真实模拟例子（[20](frontend-examples/20.json)、[21](frontend-examples/21.json)、[22](frontend-examples/22.json)）；筛选参数已在path保留。模拟只调用本地模型桩，响应里的local-demo-fast/deep不是线上应填写的模型名。DEEPSEEK_API_KEY只由后端Secret读取，任何平台响应或UI都不回显密钥。
