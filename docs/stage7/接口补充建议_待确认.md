# 阶段7接口补充建议（未实施）

日期：2026-11-16。以下是供更新冻结约定的具体提案，**不是现有接口，也不是本轮真实HTTP返回**。保持当前机构管理、AI设置、课程方案、反馈、报告和财务接口不变。

## 一、学科模板的版本与导入

### 管理接口

- GET /api/ops/subject-packs：返回items；每个包含key/name/current_published_version/versions。versions含pack_version、整数version、status=draft|published和发布时间。
- POST /api/ops/subject-packs：创建某学科的草稿版本。学科仍限已确认的一期四类，不在本次开放舞蹈。包内pricing只能null，不带机构course_type_id。
- PUT /api/ops/subject-packs：请求带key、pack_version、当前整数version和完整content，只能改草稿；旧整数version为409 version_conflict、details.latest为当前完整对象。已发布版409 invalid_state（内容已冻结）。
- POST /api/ops/subject-packs/{key}/versions/{v}/publish：{version}，校验整个包及所有引用，通过后原子发布并成为当前发布版本；内容此后不可修改。

创建/编辑例子（课程/阶段/班型字段继承§4.1原校验；下面只列小型完整包骨架）：

```json
{
  "key":"music_interest","name":"音乐兴趣","pack_version":"0.2","version":1,
  "content":{
    "courses":[{"key":"piano45","name":"钢琴一对一","group":"主修","form":"one_to_one","minutes":45,"duration_text":null,"pricing":null,"active":true}],
    "stages":[{"key":"foundation","name":"基础阶段","default_months":{"min":1,"max":3},"anchor":"start","anchor_node":null,"offset_months":0,"active":true}],
    "rules":{"exam_sprint_before_grade":true,"insert_holiday_camp":true,"art_exam_end_after_school_exam":false,"art_transition_stage":false,"mock_exam_schedule":false},
    "calendar":[],
    "course_rules":[{"stage_key":"foundation","required":["piano45"],"recommended":[],"exclusive":[],"units":{"min":6,"max":20}}],
    "classes":[{"key":"piano_interest","name":"钢琴兴趣","dimensions":[{"key":"reading","name":"读谱","order":1,"feedback_tags":[]}],"options":{"compare_previous":true,"mock_exam":false,"require_artwork":false,"renewal_suggestion":false,"stats":["lessons","attendance","repertoire_done"]}}],
    "content_types":[{"name":"课程介绍","required":["适合谁","报名方式"],"optional":[]}],
    "constraints":{"prohibited_terms":["包过"],"policy_source":"只使用机构提供的官方文件","student_privacy":"只用昵称","report_basis":"只按老师要点与评分写"},
    "tone":"亲切、鼓励"
  }
}
```

POST成功201、PUT成功200，返回同形对象并带status；整数version由服务器生成/递增，pack_version字符串在该版本生命周期内不变。既有内置版本0.1保留。

### 引用与现有机构

- courses/stages/classes各自key唯一，key在该学科后续版本保持身份；不以名称或数组顺序定位。
- course_rules只用stage_key和课程key；不得带本机构真实ID。发布时检查引用存在，导入时映射成§4.1.5的stage_type_id及正式课程ID；所有写入在机构repo同一事务内完成。
- calendar节点key、维度key继续稳定，不因显示名改变而改key；报告快照和价格快照不回写。
- 首次开通复制当前发布版本；老机构不会自动更新。主管显式POST /api/settings/subjects {key}才导入新版本，同版本幂等。
- 采用追加方式：已有key保留机构原值及价格；新增key追加；已有同名项仍按§4.1.1保留，不覆盖，也不把同名手建条目擅自认作模板key。机构已有stage-rules不覆盖、日历只补缺key；班型/维度不覆盖。选课规则仅追加缺失阶段的规则，且所有引用必须映射正确；不满足则整次422回滚，不能留下半个包。
- 响应保持现有settings/subjects数组格式（key/name/pack_version），界面可另读平台发布说明提示哪些内容由机构继续维护。不自动停用或删除平台新版移除的机构条目。

## 二、风格包

### 资源协议

新增只读地址见《阻塞说明》第二节。asset_path是ZIP内assets/之后的规范相对路径，例如cloud.png；拒绝..、绝对路径、反斜杠、空字节、网络URL和未列入包清单的文件。thumbnail可通过同一资源入口读取，不公开R2桶。

授权不按请求里的tenant_id：

| 使用方 | 授权来源 |
| --- | --- |
| 平台超管 | 现有Access（启用时）+平台会话+owner；允许草稿 |
| 机构用户 | 本机构当前可选包及权限，或本机构已有文档锁定的旧版本；老师只可读取report/feedback_card资源，不借此取得方案/文章权限 |
| 家长/学员 | 本人或有效绑定孩子的已发送方案/已发布报告；包、版本从该文档可见修订读取 |
| 公开分享 | 有效token固定修订；失效统一404，不暴露具体原因 |

返回原图二进制，按实际格式给Content-Type、nosniff；家长/分享图不做公共缓存，权限撤销后下次访问立即生效。包停用只影响新选择，不删除历史资源。

既有manifest保持原始相对引用，响应另带asset_base（及必要的asset清单）；前端以asset_base解析manifest内资源。原始manifest/图片字节按pack_id+pack_version锁定，不为新版本覆盖旧对象。

### 上传、预览、发布、默认包

- upload的multipart字段固定file；返回pack_id、pack_version、整数version、status=draft、checks:{errors,warnings}及manifest。结构/格式/大小/字体/组件/静态对比度错误返回422，未创建可发布版本；只提示的图片宽度问题仍可存草稿。
- 检查ZIP压缩与解压总量都不超过10MiB、图片单张不超过2MiB；只收manifest.json及PNG/JPEG/WebP资源，不收SVG/字体/脚本/HTML/隐藏额外文件；检查CRC和真实格式，不只看扩展名。
- preview请求{}；按manifest支持的doc_types返回预览数组，不请求机构个人数据、不调用AI、不保存业务文档。示例：

```json
{"previews":[{"doc_type":"report","render_data":{"example":true,"student":{"nickname":"示例同学"},"texts":{"progress":"平台示例进步","focus":"平台示例关注点"}},"manifest":{"id":"newyear-red","version":"0.9.0","doc_types":["report"]},"asset_base":"/api/ops/style-packs/newyear-red/versions/0.9.0/assets/"}]}
```

此处render_data/manifest为缩略提案；正式实现会返回对应文档的完整示例数据和完整原manifest，前端复用既有渲染器。

- 发布请求沿用{scope:"admin_only"|"tenants"|"all",tenant_ids:[…]}，需要draft的当前整数version以防并发。tenants必须非空且全部存在，all/admin_only不带机构ID；作用于该次发布版本。发布只改变之后可选的当前版和范围，旧文档仍锁原版本和资源。
- default沿用{doc_type,pack_id}，doc_type包括plan/report/feedback_card/article；目标须有支持该类型的已发布版本。默认设置按类型独立保存。若某机构不在默认包发布范围或该包已停用，新建时只从该机构仍可用的已发布包中选择回退；一个可用包也没有时返回明确错误，不绕过scope。旧文档不换风格。

### 对比度口径

上传时按WCAG相对亮度公式计算静态token：ink/paper、muted/paper均须≥4.5:1；主色背景至少白色或ink一种文字达到4.5:1，返回可用文字模式。颜色字段须可计算的固定颜色，不能填脚本或CSS表达式。

use_tenant_primary覆盖色、图片背景及最终text_mode_resolved依赖实际机构和图片，不能声称上传时已经验证；前端预览/导出使用真实图重新检查，必要时用panel及通过检查的文字模式。这个补充不会让后端存HTML或任意CSS，也不放宽§6字体/组件白名单。
