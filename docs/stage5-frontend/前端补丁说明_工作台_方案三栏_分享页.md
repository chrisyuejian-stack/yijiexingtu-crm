## 新增 / 修改

| 文件 | 内容 |
|---|---|
| `src/tenant/yx-home.js`（新） | 左侧“日常”下新增“招生工具”：工作台（三个工具卡、本月方案与待跟进、最近方案、开通进度 5 步并可跳到对应设置）、课程方案列表（状态筛选、搜索）。招生内容助手、成长报告显示“即将开放”，阶段 5/6 接口上线后接入。 |
| `src/tenant/yx-plans.js` | 编辑器改为三栏：左表单、中间“家长看到的样子”实时预览（金额保存后更新）、右侧费用合计与 AI 助手占位（阶段 5 接入）；新增公开分享页 `yxSharePage()`：请求 `/api/share/{token}`，失败统一显示“链接已失效”。 |
| `src/tenant/app.js` | 导航插入“招生工具”组；启动时 `/s/{token}` 直接进入分享页，不请求 me、不进登录。 |
| `src/tenant/v2a.js` | 工作台“去填写”可直接打开机构设置的对应分类。 |
| `src/share/index.html` | 分享页外壳：加载机构端 `/assets/tenant.css`、`/assets/tenant.js`（无内联脚本、无平台名称、noindex）。 |
| `src/tenant/yx.css` | 三栏、预览、工作台、分享页样式；打印时分享页不被隐藏。 |
| `scripts/frontend-bundle.mjs` | 追加 `yx-home.js`。 |
| `tests/yx-frontend-stage2.test.mjs` | 安全检查覆盖新文件；确认分享路径先于登录流程处理。 |
| `tests/share-shell-stage5.test.mjs` | **一处修改**：原断言“外壳不含 tenant.js”改为“外壳引用 `/assets/tenant.js` 且不含登录用的 turnstile-key”。原因：分享页复用机构端脚本渲染方案，以免多出 dist 文件；启动流程对 `/s/` 先行返回，不进入 CRM（由上一条测试保证）。其他断言不变。 |
| 阶段 4 补丁原有文件 | `v2p.js`、`c2.js`、`yx.js`、`scripts/yx-preview.mjs` 原样包含。 |

后端、迁移、构建脚本未改，dist 仍 12 个文件。
