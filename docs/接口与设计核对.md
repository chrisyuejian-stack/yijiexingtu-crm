# 接口与设计核对

依据：接口约定 v0.2、学科模板 v0.1、设计稿 v2、渠道 CRM 2026-11-12 源码及工具站 v6。记录日期：2026-11-13。

## 已补齐的主要问题

v0.2 已补充根地址登录识别机构、consultant / parent 角色、价格快照与重算、家长绑定、复用旧反馈确认流程、AI 配额预占。用户已确认四项标星产品选择，见《项目决策与范围》。

## 开发前需要统一的接口细节

这些是后端核对意见，尚未写成新的已冻结接口版本。上传原件保持不变。

| 位置 | 核对结果 | 后端处理建议 |
| --- | --- | --- |
| §1.2 登录 | 只对实际候选跑 PBKDF2，无法保证不同候选数量的耗时一致 | 根登录始终跑固定数量的校验槽，不足用假记录补齐；限制候选上限。手机号平台索引在创建、改号、变更角色与停用时保持一致 |
| §1.1、§2.3 | 旧 resolveTenant 遇停用/到期返回 404，新协议要求已登录机构接口 403；旧 Cookie 按 slug 限定路径 | 新增根会话识别，在认证后的机构状态检查返回 tenant_expired；公开分享继续中性 404。机构状态检查不能顺带删除原本仍有效的会话 |
| §4.1.2、设计图10 | 新报价课与旧教务 course_types 的计价、时长不同 | 先将报价课程和排课课程作为不同领域，预留本机构 course_type_id 映射，不把报价保存自动写成排课。旧排课只允许 30/45/60 分钟；美术 90–120 分钟与半天/全天若要实际排课，需要单独扩展约束与界面 |
| §4.3.1 | 文字要求稳定 line_id，但两份课程行示例均未列出；阶段也需稳定标识 | 课程行持久化 line_id；新建由服务器生成，更新校验唯一性和原课程身份。stage_key 稳定，用于快照与修订匹配 |
| §4.3.2、范例 B | 一个集训打包价包含多条展示课程，接口尚未表达“包含项” | 补充计费行与包含项的关系，以及按期/学期/月/课包的数量字段，避免同一集训重复收费。课包内含课时和包数分别表示 |
| §4.3.1、§4.3.6 | 老课程停用不影响旧方案保存，但检查仍把停用课程当阻断；价格快照与当前价目表判断冲突 | 有有效快照的历史行可保留，停用或变价提示 warning；新行无价格/不属本机构仍拒绝。不要迫使已发送文件改用新价格 |
| §4.3.4 | AI 推荐按当前价目表计算，采用时价目表可能已经变更 | 建议返回 price_list_rev；采用时重新校验版本。发生变化返回冲突和最新计算，不能静默改变用户看到的报价 |
| §4.3.5、分享 | 已发送/签约方案禁 reprice，但普通 PUT、恢复版本、分享链接尚未锁定同一发布内容 | 明确已发送版本及分享读取的修订，防止通过普通 PUT 绕过价格锁定。已发家长的内容与编辑草稿分开 |
| §4.3.2、范例 A/B | “自然周”“按天折算后取整”未指定取整方式；样例 B 2027.09–12 写16周，与日历约17.4周不同，2028.01–03写10周也不是日历周数 | 统一区分日历跨度与实际教学周。范例中的教学周数不能用日历周函数硬凑；明确展示字段和排课频率的口径 |
| §4.5.3、范例 D | 报告 schema 仅示例上课次数/出勤/完成曲目，设计有集训天数、模拟考次数、距统考天数 | 增加按班型选择的统计项，声明来源、单位、日期口径和可否人工覆盖；统考日期仅默认月份时不生成精确倒计时 |
| §4.5.3 | 前文只允许 ready 发布，后文允许老师跳过 ready | 老师获发布授权后可一步完成与发布，但仍执行相同的打分、作品图和必填内容校验 |
| §2.4 | 预占120秒自动释放；模型/重试如果超时后仍结算，可能突破上限 | 为任务设置明确截止时间；在预占有效期内完成或续租，过期后禁止无条件结算。结算按有效 hold 原子执行且只能一次；批量预占和账号并发限制分开 |
| §2.4、AI 重试 | 成功才计次，HTTP 重试可能重复耗用；没有幂等键约定 | 新增请求幂等键和请求结果状态，相同请求不重复调用/扣次。北京时间跨日按预占所属日期结算，reset_at 清晰可查 |
| 设计图12、§4.1.6 | 设计写“名字相同”才对比，接口要求按不可变 key 对比 | 按 key 比较；维度改名仍可比较。报告保存维度快照，历史名字不随设置改动 |
| §4.3.8、工具站源码 | 文档称浏览器打印“和 v6 一样”，实际 v6 为 html2canvas + jsPDF | 新版可采用前端打印，但需要独立验收中文字体、分页、图片清晰度及移动端行为；不能按 v6 已验证处理 |
| §4.1.7 品牌 | 提到机构可改主色/二维码，但只列 GET /settings/brand | 后续补最小 PATCH 请求，仅接受机构可改字段；名称/logo/登录背景仍由平台维护 |
| §4.10 家长停用 | 最后一个孩子解绑后重绑自动恢复，与员工手动停用的区别未表达 | 记录停用原因；仅自动解绑导致的停用可随重绑恢复，不能绕过员工主动停用 |

## 范例金额核对

- A：800 + 3,600 + 3,640 + 3,360 = **11,400 元**。计费课时为4 + 4 + 26 + 15 = **49课时**，另含集训1期。按设计课程库的钢琴200元、乐理80元、冲刺260元及集训2800元，可复算各阶段。
- B：14,000 + 16,000 + 26,000 + 12,000 = **68,000 元**。其中统考冲刺4个月合计26,000元，可按6,500元/月表达；其余阶段按期计费。住宿1,500元/月为可选费用，不进入课程总费用。
- 这只是设计数据核算。实际计价函数、快照防篡改与验收测试尚未编写。
