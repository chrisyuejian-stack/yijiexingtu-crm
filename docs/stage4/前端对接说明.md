# 阶段4前端对接说明

依据冻结接口v0.3.5。后端起点为已验收阶段3源码，用户提供的阶段3前端补丁8文件已原样接入；此后未修改`src/tenant/*`、`src/console/*`、`src/ui/*`。合并时保留前端方对这些目录的后续修改，阶段4主要合入`src/server/*`、0021迁移和新增测试。没有增加前端哈希锁定测试。

## 路径与权限

继续用登录返回的`api_base`。根员工会话为`/api`，机构路径会话为`/{slug}/api`。下表路径均相对`api_base`。请求沿用Cookie与同源JSON约定；样例不携带测试Cookie或真实凭据。路径机构与会话不符返回404，机构到期或停用返回403`tenant_expired`，恢复后有效会话继续使用。

| 方法 | 相对路径 | 用途 |
| --- | --- | --- |
| GET/POST | `/plans` | 筛选分页列表/创建 |
| GET/PUT/DELETE | `/plans/{id}` | 当前工作稿/保存/删除草稿 |
| POST | `/plans/{id}/duplicate` | 复制为新草稿，可带`student_id`、`source_lead_id`、`title`、`revision_id` |
| GET | `/plans/{id}/revisions` | 修订列表，`id`用于恢复或指定导出，`version`为该次方案版本 |
| POST | `/plans/{id}/revisions/{rev}/restore` | `{version}`，恢复为新修订 |
| POST | `/plans/{id}/skeleton` | 程序骨架建议，不保存、不调用模型、不扣AI用量 |
| GET | `/plans/{id}/check` | `blocking/warnings/passed` |
| GET/POST | `/plans/{id}/reprice` | 预览/确认刷新快照；POST带`{version,line_ids?}` |
| POST | `/plans/{id}/send` | 可带当前`version`，检查通过后冻结并更新发送指针 |
| POST | `/plans/{id}/sign` | `{revision_id?}`，默认最近发送版本；只能选择已发送修订 |
| POST | `/plans/{id}/archive` | 可带`version`，家长不再显示，链接立即失效 |
| POST | `/plans/{id}/export` | `{revision_id?,force?}`，返回`render_data`和`manifest`，并记导出事件 |
| GET/POST | `/plans/{id}/share-links` | 链接列表/创建；POST`{expires_in_days:30}`，1–180天 |
| DELETE | `/plans/{id}/share-links/{link_id}` | 立即作废，可带链接`version` |
| GET | `/styles?doc_type=plan` | 方案起步风格当前版本清单 |
| GET | `/styles/{pack_id}/versions/{v}` | 旧文件锁定的manifest |
| GET | `/compliance/terms` | 平台与本机构补充禁用词 |
| GET | `/parent/plans/{id}` | 自己孩子当前有效的已发送/已签约快照 |
| GET | `/parent/children/{student_id}/feed` | 当前为方案时间线，反馈与成长报告待阶段6加入 |
| GET | `/parent/media/{image_id}` | 当前可见内容实际引用的图片，绑定撤销即失效 |

公开接口在主机构域名下：`GET /api/share/{token}`、`GET /api/share/{token}/media/{image_id}`。创建返回`https://{TENANT_HOST}/s/{token}`；**当前`/s/{token}`同样返回JSON数据，未提供分享页HTML**。前端需制作独立的公开页面入口并请求`/api/share/{token}`，保留失效时中性404、`noindex`和`Referrer-Policy: no-referrer`。不要让公开分享页落到需要登录的CRM外壳。

员工方案权限沿用`can`：主管、教务、顾问编辑及分享，财务只读。老师不能读取方案和价格。家长与学员只能读取关联孩子的已发送/已签约版本，不能调用编辑、历史修订和内部检查。`plans`模块关闭时私有方案和公开分享同时404。

列表支持`student_id`、`lead_id`、`status`、`q`、`offset`、`limit`；默认50、最大200，返回`items/total/next_offset`。修订列表、链接列表和时间线也支持该分页格式。新DTO不含`tenant_id`。

## 编辑、稳定ID和金额

新建只需学员或线索至少一个、学科、标题，风格可省略。默认空工作稿可逐步填写。PUT带顶层`version`；可传整体方案对象，也可用`{version,doc:{...}}`。不要把`computed`、`snapshot`、`stage_snapshot`当输入依据，服务器会忽略客户端金额与快照。

新增阶段/行不传ID或用唯一`tmp_`ID，保存后按`id_map`替换本地所有引用。未提供ID时映射键为`stages[0]`、`lines[0]`等，建议前端统一使用`tmp_`。服务端正式ID为`stk_`和`ln_`；同一对象后续保存保留ID。阶段、课程行及分期的临时引用会一起改写。已有行不能换`course_id`；删除再新增才能换课。

报价课程与排课课程分开。五种`qty`分别为`units/terms/semesters/months/packages`，只能带匹配的一种正数、最多两位小数。不按周自动填课时。`includes`仅展示，客户端给包含项金额也不计费。可选费用不计总价、课时合计或分期。

JSON金额以元返回；快照中明确标注的`amount_cents`以整数分表示。编辑器可看单价；导出、分享和家长端在`show_unit_price:false`时剔除`amount_cents`及可选费用`price_text`。隐藏模块不返回其正文。外部渲染数据含当时机构品牌、昵称和已选老师档案，不含平台品牌；只有已取得家长同意时显示全名。

阶段日期必须连续、真实且不重叠。有`teaching_weeks`时必须填`weeks_note`；周数只影响显示，数量仍由顾问确认。只有目标月份时不会生成`days_to_exam`。骨架输出临时ID和文字建议，由前端决定采用后再PUT；骨架使用本方案学科、机构规则和学员年龄，不会自动选收费课程。

`fees.installments`只能为`per_stage`或`custom`。切回按阶段时显式带`custom:[]`；自定义每项`ratio_bps`为1–10000整数，总和10000，`label`必填不超过30字，`due`为日期或null，`stage_key`为当前方案阶段或null。一次付清用一项10000。前端只展示`computed.installments`，不要自行用浮点数算最终分期。

## 版本、重算和错误处理

每次创建、保存、恢复、重算、复制和发送都会有不可变修订。工作稿继续编辑时，`sent_revision_id`不变；再发送才更新。签约可以选择历史已发送修订，家长优先读`signed_revision_id`。签约后PUT、恢复和重算返回409`invalid_state`；复制仍可用。归档后不能编辑，可复制新方案。签约不联动收费和排课。员工详情接口仍返回工作稿；查看签约正文时用export指定`signed_revision_id`，不要把后来改过的工作稿当作签约内容。

GET重算不写库，POST才刷新所选行的快照。停用或未定价课程返回422`out_of_scope`；旧方案可保留这些快照继续编辑和导出，只给提示。如果当前课程的计价方式已经变更、旧数量字段与新方式不兼容，不能推测新数量，刷新会返回422；删除旧行、重新选课并填写对应数量后再保存。

| 错误 | 前端处理 |
| --- | --- |
| 409`version_conflict` | `details.latest`是当前完整工作稿；让用户选择刷新后继续，勿覆盖 |
| 409`price_changed` | 新增行采用的价目表已过期，`details`含当前版本与重算结果；确认后再保存，本次未写入 |
| 422`validation_failed` | 按`details.fields`定位字段 |
| 422`check_failed` | 展示阻断项，处理后重试；分享不能强制放行 |
| 403`tenant_expired` | 机构到期/停用提示，不清空本地登录态 |
| 私有404 | 资源不存在、外机构或模块关闭，统一提示 |
| 公开404 | 统一失效页，不透露具体原因 |

导出默认工作稿，可指定`revision_id`。只有主管可用`force:["over_budget"]`继续超预算导出；禁用词不能强制放行。生成链接固定使用创建时最近发送的修订，即使工作稿已变也不变。令牌只在创建响应里出现一次；列表没有可恢复的原URL，前端应提示用户当场复制。旧链接不会自动改成新发送版本。

风格读取当前提供三个无外部资产的起步manifest，版本1.0.0；平台上传、发布与管理在阶段7。旧方案保存和导出使用原manifest，不跟随风格包更新或停用。

图库内部文件URL为`{api_base}/gallery/{id}/file`，财务可读取其有权读取的方案所引用文件，不可浏览全部图库。家长/分享使用各自的媒体URL，不能复用员工文件地址。隐藏图片被历史修订引用时保留文件，隐藏模块的图片不会经家长或公开接口泄露。

## 前端仍需完成与验收

- 课程方案编辑器、检查抽屉、修订选择、分享管理与公开页面；本阶段后端未制作这些界面。
- 根据manifest排版，导出用浏览器A4打印；中文字体嵌入、分页不截阶段块/表格、300dpi主图和微信打开后的打印/保存效果须单独验收。
- 主图文字区亮度/方差与自动文字模式由前端计算，把`text_mode_resolved`保存。后端保存结果，对纯色封面计算对比度；有主图时给前端检查提示，不声称完成图片文字区采样。
- 设置页的`qr_image_id`与旧CRM的`consultant_qr`先维持两处存储，不自行合并或双写。

[前端接口示例.json](前端接口示例.json)及`examples/`内文件均取自本地实际HTTP测试请求和响应。每组来自独立测试场景，ID不可跨组拼接；可按结构制作模拟数据。二进制图片响应以`binary/mime/base64`描述实际字节，HTTP本身仍返回图片，而非JSON。没有真实客户数据、Cookie或外部服务凭据。
