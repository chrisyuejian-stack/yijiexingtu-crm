# 阶段4 · 课程方案交付说明

本阶段依据您确认的冻结接口v0.3.5，接着已验收的阶段3源码完成课程方案后端。您提供的阶段3设置页面前端补丁已原样覆盖并复测，后端没有另改前端页面。没有新增需要您决定的事项。

机构现在可以创建方案，分阶段选报价课程，保存和恢复历史版本，复制给另一位学员。费用由服务器按保存时的价格计算，支持按课时、按期、按学期、按月和课包；集训包含的训练内容不重复收费，可选住宿等费用另列。日历周自动计算，手填教学周必须解释原因。

分期可以按阶段，或按您确认的比例规则自定义。服务器用整数分分配尾差，保证分期合计等于总价。例如300.01元各付一半，结果是150.01和150.00元。音乐与美术两个完整范例分别得到11,400元和68,000元。

价目表更新不会悄悄改变旧方案。顾问可先看重算预览，再明确确认刷新价格。发送给家长的版本和分享链接固定保留当时内容，之后改工作稿不影响它们；再次发送才更新家长端。签约可以选择已发送版本，之后锁定编辑，需要调整时复制新方案。第一版签约不自动产生收费、排课或课时包。

后端会检查预算、禁用词、停用课程、旧价格、档案占位内容和图片清晰度等。导出接口返回排版数据，单价关闭时不会给家长或分享页返回单价。超预算可由主管确认后继续导出，并留审计；禁用词不能强制放行。家长只能读取自己孩子已发送或已签约的方案，解绑立即失去权限。分享令牌只首次返回，数据库只存哈希；失效链接使用统一的404页。

实际测试结果及命令见[测试结果](测试结果.md)，文件与迁移明细见[变更清单](变更清单.md)。原有迁移0001–0020保持不变，只新增0021；新方案、修订和分享记录已进入完整加密备份。

本阶段没有制作课程方案前端、公开分享页面或PDF排版。Claude可按[前端对接说明](前端对接说明.md)和[真实请求响应JSON](前端接口示例.json)继续对接。中文字体、A4分页、图片打印和微信分享页效果仍须前端实际验收。家长时间线当前只有方案，反馈与报告将在阶段6补入；AI生成和用量配额在阶段5完成。

图库二维码与旧CRM二维码仍按您的要求分开保存，本阶段不统一。没有连接真实Cloudflare、DeepSeek或线上数据，也没有创建远程部署；您现在无需敲命令或操作Cloudflare。

阶段4交付后暂停，等待您验收，再开始阶段5。
