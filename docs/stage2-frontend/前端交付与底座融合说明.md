## 三、后端的小改动（Claude，均有测试）

1. **根地址页面**（worker.js `dispatch`）：机构域名下 `/` → 302 到 `/login`；`/login` 和 `/app`、`/app/...`（与机构路径同一份页面白名单）给同一个前端外壳，基础路径 `/`。只给静态外壳，不读机构数据；登录状态由前端调用 `/api/me` 判断。其他路径仍 404。
2. **`/api/me` 增加 `tenant_slug`**（员工 me）：根地址登录没有机构路径，前端靠它取机构品牌（公开接口 `/api/public/tenant-brand?slug=`）和显示老师/家长登录地址。不增加数据库查询（`P1 /api/me` 两趟预算仍通过）。
3. 新测试 `tests/yx-frontend-stage2.test.mjs`（3 项）：根地址路由、me 的 `tenant_slug`、新前端文件无 HTML 注入/内联样式、已打进机构端脚本。
