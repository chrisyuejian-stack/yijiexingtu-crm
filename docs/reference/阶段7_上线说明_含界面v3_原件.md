## Cloudflare 设置

**这次界面更新本身不需要任何新设置。** 下面这些是阶段 5–7 原本就要求的，如果以前还没配过，要补上：

1. Pages 的 Bindings 里有 CHANNEL_DB、CHANNEL_MEDIA、CHANNEL_BACKUPS 三个绑定。
2. Pages 普通变量有：
   - TENANT_HOST、CONSOLE_HOST（两个不同的域名）；
   - ACCESS_MODE=on、ACCESS_ISSUER、ACCESS_AUD、ACCESS_EMAILS；
   - TURNSTILE_MODE=on、TURNSTILE_SITE_KEY；
   - REFERRALS_MODE=off。
3. Pages 的 Secret 有：FIELD_KEY、BACKUP_KEY、HMAC_KEY、PW_PEPPER、PLATFORM_SETUP_KEY、PLATFORM_PHONE_HMAC_KEY、TURNSTILE_SECRET。
4. 平台域名开启 Cloudflare Access，只允许授权邮箱访问。

## DeepSeek 设置

1. 在你自己的 DeepSeek 账号里取得 API Key，放进 Pages 的 Secret，名字是 **DEEPSEEK_API_KEY**。只放 Secret，不要写在普通变量里。
2. 登录平台后台，打开 **“AI 用量与每日上限”**（原来的“AI 模型”页面）：
   - 填快速模式和深度模式的模型名，必须是你 DeepSeek 账号当前支持的准确名称；
   - 设每个机构每天的默认次数；
   - 不要照抄预览环境里的 preview-fast 或 local-demo 模型名。
3. 没填 Key 或模型名时，机构端点 AI 会提示“还没开通”，原来的 CRM 业务照常使用。

## 上线后多看几项（界面 v3 相关）

- **平台后台 › 模版与风格包**
  - 上传 GPT 部署资料里的示例风格包，检查结果应显示“1 项提示”（示例图太窄）。

- **平台后台 › 学科模版包**
  - 新建一个草稿，保存后先不发布，确认测试机构没有变化。
  - 草稿留着无害；要发布再点“发布”。
- **方案**
  - 测试机构打开方案编辑器，在“样式”里切换模版，中间预览的封面会跟着变。
  - 上传一张深色照片和一张浅色照片当主图，看封面文字是否都清楚。
  - 导出 PDF 看一遍。
- **课后反馈卡片**
  - 等测试机构确认一条课后反馈后，在家长端“课后反馈”看一下卡片样式。
