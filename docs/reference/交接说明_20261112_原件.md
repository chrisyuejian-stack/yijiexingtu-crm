## 3. 产品已定事项

### 定位
- 艺界星途：独立公司 / 业务线，用智能体和 AI 赋能艺术机构的日常运营。
- 第一批客户：**音乐和美术机构，包括兴趣类和艺考类**；舞蹈后期再做。
- 三个工具放在**艺界星途 CRM 的「招生」板块**里，作为独立网页工具（每个工具是一个独立页面，顶部有“← 返回 CRM”）。
- 第一版三个工具：
  1. **招生内容助手**（由枫琴工具站 v6 的公众号编辑器改造）：公众号文章、朋友圈（3 种长度）、小红书、海报文字、家长群通知、活动邀请；按场景起草，事实只来自机构档案和勾选素材，没依据的标黄；广告法合规检查（禁“包过”“100%”“第一”等）。
  2. **课程方案与报价**（由枫琴工具站 v6 的学生方案生成器改造）：咨询记录→填表；按学科模版的规则自动分阶段（显示月数 + 周数）；AI 只从课程库选课；金额由程序按价目表计算；**目标课程总费用严格不超**；给 2–3 种同预算配法；每个页面底部都有“一句话调整”输入框。
  3. **学员成长报告**（新增）：老师手机上点几个要点或语音 → AI 写成发给家长的课后反馈；阶段报告 = 老师打分（1–5）+ AI 根据本期课后反馈起草文字 + 作品图；AI 不编造表现，不和其他学员比较；“续报建议”默认不附。

### 域名与登录
- 官网：yijiexingtu.com（官网上有 CRM 登录入口）。
- **机构管理者**（主管、顾问 / 运营、教务）登录：edu.yijiexingtu.com
- **老师和家长**登录：edu.yijiexingtu.com/机构代号（例如 /demoschool），页面显示该机构的 logo 和背景图。代号由超级管理员设置。
- 都用手机号 + 密码。

### 账号、角色与收费
- 多机构 SaaS：一个系统、一个数据库，所有数据带机构 ID，服务器端按登录账号的机构过滤（前端传来的机构 ID 不信任）。
- 角色：超级管理员（Chris，机构不知道其存在）· 机构主管 · 顾问 / 运营 · 教务 · 老师（只看自己的学员）· 家长（只看自己的孩子，一个家长可关联多个孩子）。
- **收费**：按管理账号（主管、顾问 / 运营、教务）数量收费；新机构先发**固定天数的试用账号**，到期自动停用。
- **AI 用量不分档**：所有机构统一一个每日上限（建议试点期每机构每天 100 次，待 Chris 确认），用完当天暂停、次日恢复。
- 学员第一版由机构手动录入；以后与 CRM 线索页打通（接口预留“来源线索 ID”字段）。
- 家长另有一次性分享链接（随机令牌、可设有效期、可作废），给还没开账号的意向家长看课程方案。

### 品牌露出
- 管理者登录页：艺界星途品牌为主。
- 机构管理端：机构 logo 为主；侧栏底部小字“艺界星途”+ 客服入口；AI 面板标题旁小字“艺界星途 AI”。
- **老师 / 家长端、导出的 PDF / 长图 / 文章：只有机构品牌，不出现艺界星途**。
- 机构名称、logo、登录背景只能由超级管理员改，机构自己不能改。

### 学科模版包（Claude 起草，Chris 已确认先用）
- 四个包：音乐兴趣、音乐艺考、美术兴趣、美术艺考。每个包包含：课程库（课程名 / 课程组 / 形式 / 时长，无价格）、阶段规则（起步期、常规阶段长度、固定节点）、招生内容类型（必有 / 可选小节）、成长报告维度。
- 默认节点：兴趣类寒暑假集训（1–2 月、7–8 月）、考级季（默认 7–8 月和 1 月）、汇报 / 画展（6 月、12 月）；艺考类暑期集训 7–8 月、统考冲刺 9 月到统考（默认 12 月，按省份改）、校考次年 1–3 月（只给报校考的学生排）。
- 成长报告维度：音乐兴趣 = 读谱识谱、节奏感、演奏 / 演唱技术、音乐表现力、练习习惯、课堂专注与自信；美术兴趣 = 观察力、想象与创意、色彩感受、画面构图、动手能力、专注与完成度（素描色彩班另有一套）；艺考类加“模拟考成绩”一栏（老师填数字，AI 不推算）。
- **两种改法**：机构可以在设置里手动增删改课程、节点和规则；也可以在 AI 助手里由顾问 / 教务用一句话调整（例如“我们这里考级在 11 月”），AI 给修改卡片，主管确认后写入。
- 完整内容在 Chris 的文档「艺界星途 · 机构 AI 工具站 产品说明 v0.1」的「学科模版包」页签（见第 6 节）。

## 4. 设计规范（已出，Chris 尚未正式反馈）

风格与枫琴艺术统一，色彩比枫琴更丰富一点。logo：**Chris 有 logo，稍后提供**，设计稿里先留“LOGO”虚线占位。

| 用途 | 颜色 |
|---|---|
| 夜紫（深色背景，如登录页左侧） | #1E162E |
| 墨紫（正文） | #2B2040 |
| 星紫（主色、主按钮、课程方案） | #6A35B8 |
| 琥珀橙（点睛，来自枫琴） | #F4A85B |
| 奶油（页面底） | #FBF8F4 |
| 雾紫（次级底） | #EFE9F6 |
| 辅助文字（满足 4.5:1） | #5E5474 |
| 珊瑚（招生内容） | #FF7A59 |
| 青绿（成长报告） | #16A394 |
| 天蓝（音乐学科） | #3E8BFF |
| 日光黄（美术学科） | #FFC53D |
| 玫红（舞蹈，预留） | #E8478B |

- 字体：中文 Noto Sans SC / PingFang；英文点缀 Cormorant Garamond 斜体（枫琴同款）。正文 15，页面标题 28。
- 圆角：卡片 16、按钮 10、标签 999；阴影只用一层轻投影；线性图标 1.8px；不用 emoji 做图标。
- AI 建议一律用“卡片 + 依据 + 采用 / 不要 + 可撤销”的形式。
- 示例机构：星光琴行（音乐）、星光画室（美术）。所有价格、学员都是示例数字。
