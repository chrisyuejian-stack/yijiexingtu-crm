# 界面对齐设计稿 v3（2026-11-16）

基准：《艺界星途_阶段6_前端融合源码_20261116.zip》。只改前端（`src/tenant/`、`scripts/frontend-bundle.mjs`）。后端、迁移、`build.mjs`、`wrangler` 配置都没改，所以**部署不碰数据库，也不需要新的 Cloudflare 或 DeepSeek 设置**。

功能不重做。7 个阶段已有的接口和数据都没动，这次只调界面和交互，让它对齐《艺界星途 · 机构 AI 工具 设计稿 v3》。

## 已完成（第 1–6 批）

| 批次 | 页面 | 对齐内容 |
| --- | --- | --- |
| 1 | 全局外观与导航 | 深色侧栏，选中项旁有琥珀小圆点；纸白底色，主要按钮用墨色；紫色只给 AI；状态用“圆点 + 文字”；标题用宋体，关键数字用斜体衬线。导航按 v3 调整：招生（线索 · 推广中心 · 招生内容 · 课程方案 · 成长报告）、课程与教室（排课课程与教室 · 报价课程与价目表 · 阶段与节点）、机构设置（机构档案 · 品牌与图库 · 成长报告维度 · AI 用量 · 基本设置）。工作台不再出现在导航里，原地址仍能打开。 |
| 2 | 招生内容 | 列表页：今日 AI 用量、“从场景开始”卡片、类型页签带数量、状态和作者筛选、表格。编辑器：左边是“文章 / 品牌与模版”；中间显示排好版的文章，点哪一段就改哪一段，插入的模块放在选中的那段下面；右边是内容助手（起草 / 改写 / 资料核对 / 配图），建议卡片上有“填入 / 换个说法 / 不要”。顶栏显示找不到依据的句子数和广告法用词数。 |
| 3 | 课程方案编辑器 | 左边分“内容 / 样式”两个页签。内容是 7 个模块的手风琴：一次只展开一个，每个模块有一句摘要，还有“给家长显示”的眼睛开关。课程安排按阶段切换。样式页签里改模版、封面主图、封面文字和显示开关。中间是 A4 分页预览，顶部有页码条。右边是方案助手（整理咨询记录 / 阶段与课程 / 润色文字），带阶段周数条、合计和上限，底部有常用说法和一句话调整。顶栏显示“检查 · N 项”。 |
| 4 | 成长报告编辑器 | 左边是全班学员和进度条，底部有“为未开始的 N 人起草”。中间依次是本期概况（标明来自 CRM 还是手动改过）、老师打分（圆点打分，显示上期分数和变化）、四段文字（AI 建议显示在每段下面，可以填入、换个说法或不要；AI 填入的段落是淡紫底，人改过就变回白底）。右边是手机宽度的家长预览。顶栏有“发布已完成的 N 份”。 |
| 5 | 老师手机端 | “今天 N 节课”放在深色卡片里。每节课一张卡片，显示待写、已确认、已退回或还没上。下面是“待处理”。写反馈页依次是：出勤按钮、“今天学了 · 来自学员曲目单”、“表现 · 按打分维度”、补充一句、“发给家长的话”（四段可以直接改）。提交按钮固定在底部。 |
| 6 | 设置页 | 报价课程与价目表：课程组页签带数量；表格有计价方式和价格两列，没定价的标红点；右边是“用一句话改设置”和五种计价方式说明。阶段与节点：节点日历改成 12 个月的甘特格子，点格子就能选月份；右边也有“用一句话改设置”。成长报告维度：左边班型列表，中间维度和快捷词（可以直接改、加、删、排序），右边是顶部三个数字和显示开关，三处一起保存。 |

“用一句话改设置”用的是已有的接口：先 `POST ai/settings/propose`，再 `POST settings/changes`。主管点“确认写入”时接着调用 `approve`；其他人只是提交，等主管确认。修改记录不再占页签，从这个面板的“查看修改记录”进入。
