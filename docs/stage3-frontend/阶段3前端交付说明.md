## 调用约定（前端实际使用）

- 集合类（stage-rules / calendar / course-rules）整体 PUT，带 version；409 `version_conflict` 时提示并重新载入。
- 课程、阶段、班型、图库的增改删都带 version；DELETE 也带 version（阶段、班型的 id 放 body）。
- Excel 导入与图库上传用 `FormData`，浏览器自动生成边界；确认导入只传 `preview_id` 和 `confirm="true"`。
- 修改卡片 `change_stale` 时提示“相关设置已被修改过”。
- 没有 `prices.read` 时课程列表价格列显示“—”，编辑表单不出现价格字段，保存时不提交 `pricing`。
