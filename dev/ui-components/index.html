当前主题色

1. 颜色

主题色只用于：Logo 区、主按钮、当前导航、链接、焦点框、关键数字。不做大面积和页背景。正文与背景对比度至少 4.5:1。课程类别使用既有预设颜色，不新增任意配色能力。

2. 字体与字号

使用本机中文字体，不加载远程字体。数字使用等宽数字（tabular-nums）。

3. 尺寸与间距

间距取 4 的倍数（常用 8 / 12 / 16 / 24）。圆角：面板 14、按钮与输入框 9、标签 6、头像 10。电脑侧栏 232、顶栏 64、内容区最大宽 1360；手机左右边距 16。所有可点击区域 ≥ 44×44。

4. 基础组件

5. 交互规则

  • 新建和编辑在右侧抽屉完成，桌面宽 520，手机全屏。
  • 取消、删除等重要操作确认；未保存修改先提示。
  • 保存成功提示 3 秒；错误提示保留到手动关闭。
  • 开关保存中不可重复提交，失败恢复原值。
  • 没有金额权限，金额列和金额卡片整块不显示。
  • 遵守减少动态效果设置，使用清晰的键盘焦点。

6. 品牌与文案

  • 通用系统名为“教务管理系统”，业务页使用机构自己的名称和 Logo。
  • 此页仅为开发预览，样例不进入生产包。
  • 只使用本地资源，不加载远程脚本、字体或图标。
  • 日期、星期、时间使用北京时间，统一 24 小时制。
  • 金额只省略 .00；保留实际分位，例如 ¥12、¥12.30。
  • 存储、接口、编辑提交和 Excel 的精度不变。
