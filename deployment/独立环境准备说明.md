# 独立环境准备说明

当前是资源准备清单，**尚未创建远程资源，也不是可上线版本的部署手册**。最终交付会提供 Pages 上传 ZIP、备份 Worker、全套迁移与网页操作说明，用户无需运行命令行。

## 新项目的资源

| Cloudflare 资源 | 建议名称 | 作用 |
| --- | --- | --- |
| Pages | yijiexingtu-crm-prod | 独立托管艺界星途 CRM |
| D1 | yijiexingtu-crm-prod | 只存艺界星途机构与业务数据 |
| 私有 R2 | yijiexingtu-media-prod | 机构图库、文档相关媒体与风格资源 |
| 私有 R2 | yijiexingtu-backups-prod | 加密数据库备份与机构导出 |
| 定时 Worker | yijiexingtu-backup-prod | 调用独立数据库和备份桶 |

Pages 与备份 Worker 使用同一套**艺界星途**数据库和对应桶。原枫琴系统的数据库、桶、密钥和定时任务不参与新项目。Preview 如需远程联调，另建测试库、测试桶和测试密钥，不绑定生产资源。

底座代码中的 CHANNEL_DB / CHANNEL_MEDIA / CHANNEL_BACKUPS 是变量名称，可继续使用，但必须分别选择上表中的新资源。绑定隔离由实际数据库 ID 与桶决定，不由变量名字决定。

## 域名和外部服务

- 机构与老师/家长入口：edu.yijiexingtu.com。
- 平台管理入口：ops.yijiexingtu.com。
- 两个域名登记到新 Pages；官网 yijiexingtu.com 不在本项目本轮实现范围。
- 平台入口采用独立 Access 应用与授权范围；登录采用对应主机名的 Turnstile 配置。
- 新项目密钥全部重新生成；FIELD_KEY、BACKUP_KEY 使用独立32字节随机值的标准Base64。其余密钥按底座要求配置。BACKUP_KEY 仅在艺界星途 Pages 与备份 Worker 之间保持一致。
- 阶段2的平台手机号索引已使用独立的 PLATFORM_PHONE_HMAC_KEY，至少32字符，必须与 HMAC_KEY 分开生成和配置；此说明只列名称，不包含任何真实密钥。
- DEEPSEEK_API_KEY 仅作为服务器 Secret；模型及上限进入平台设置。当前底座尚未接入该 AI 服务。
- Access / Turnstile 的真实值待创建新服务后填写，不在源码保存。资源模板的 null 数据库 ID 表示尚未配置。

## 迁移和上传包

原 CRM 的18个迁移文件0001–0018保持原样；阶段2新增0019_identity_and_institutions.sql，阶段3新增0020_settings_and_templates.sql。后续完整部署手册按实际交付内容列出执行顺序，并在全新空库验证；本次不执行任何远程 SQL。

历史 CRM 手册曾只列0001–0011，不适用于当前源码包，不能作为艺界星途新库的部署步骤。新库也不导入枫琴的真实账号、密码、会话或业务记录。

最终 Pages ZIP 根目录直接包含 _worker.js、_routes.json、前端 HTML 和资源目录。源码、参考材料、模拟数据、测试日志、迁移文件与密钥生成工具不进入 Pages ZIP；备份 Worker 单独交付。当前构建产物用于底座验证，已包括阶段2身份与机构、阶段3设置与模板后端以及融合版阶段2前端；阶段3新界面与AI工具仍按分工在后续对接。
