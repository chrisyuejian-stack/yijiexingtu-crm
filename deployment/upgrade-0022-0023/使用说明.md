# 数据库升级资料（预演版）

当前没有执行任何远程SQL。完整中文步骤见docs/stage7/0022_0023升级与Cloudflare变量说明_预演版.md。本目录只针对已经完整执行到0021或0022的艺界星途库；新空库仍需全部原迁移。阶段7尚待接口补充，最终还需后续迁移。

1. 升级前备份并确认数据库、版本和停写窗口。
2. 执行01只读结构检查、02数量对照并保存结果。
3. 需要0022时，顺序执行0022/01.sql至18.sql；需要0023时，再执行0023/01.sql至17.sql。每个文件整体复制执行一次，触发器内部不拆分。
4. 已经完成的迁移不重跑。遇错记录步骤并由后端核对，不删表重做。
5. 完成后执行03只读检查和02数量对照，确认结构及原数据，再发布匹配应用和备份Worker。

步骤清单.json记录每个单语句文件及原迁移的SHA-256。文件是从未改动的原件提取；本地验证单步与整文件结果一致。本资料不包含密钥、远程数据库ID或可直接上线的阶段7包。
